
# mcpi

## Description

Calcule une estimation de pi par la méthode de Monte-Carlo.

Le programme `mcpi` retourne une estimation pour 100k échantillons.

Le programme `plot` génère un graphique de l'évolution de l'estimation au cours
de 500 échantillonnages.
